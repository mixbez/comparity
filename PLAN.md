# План переработки игровой логики Comparity

## Текущая логика vs. Целевые правила

### Ключевые отличия

| Аспект | Сейчас | Нужно (MVP) |
|--------|--------|-------------|
| **Рука игрока** | 1 карта за ход (draw per turn) | 3-5 карт в руке сразу |
| **Видимость значений** | Игрок видит hidden_value своей карты | Игрок НЕ знает hidden_value своих карт |
| **Режим выкладки** | Выбор: face-up (обычный) или face-down (блеф) | ВСЕ карты всегда кладутся рубашкой вверх |
| **Оспаривание** | Оспаривается 1 конкретная блеф-карта | Переворачивается ВСЯ цепочка целиком |
| **Проверка** | Проверяется только 1 карта (верна ли позиция) | Проверяется весь порядок цепочки |
| **Штраф** | Фиксированные очки (+2/-1) | Штраф получает автор последнего неверного хода (или оспаривающий) |
| **Многопользовательский** | По сути SOLO, GROUP заглушён | Полноценная ротация ходов, любой может оспорить |
| **Окно оспаривания** | 30 сек таймер после блефа | Следующий игрок решает: ходить или оспорить |
| **Конец игры** | Цепочка ≥ 10 или колода кончилась | Кто первый избавился от всех карт (или min карт) |

## План изменений

### Этап 1: Модель данных и состояние сессии

**Файлы:** `backend/src/game/engine.js`, `backend/src/redis/session.js`, `backend/migrations/`

1. **Добавить "руку" игрока в сессию Redis**
   - Сейчас: `currentTurn.card` — 1 карта
   - Нужно: `players[userId].hand` — массив из 3-5 карт
   - В Redis-сессии: `session.players[userId].hand = [{ cardId, title, imageUrl, flavorText }]`
   - **Важно**: `hiddenValue` и `displayValue` НЕ передаются клиенту в руке

2. **Изменить структуру chain**
   - Сейчас: `chain[i].isFaceDown` — опционально
   - Нужно: ВСЕ карты (кроме стартовой) всегда `isFaceDown: true` + `placedBy: userId`
   - Стартовая карта: `isFaceDown: false` (единственная открытая)

3. **Убрать `pendingChallenge` из сессии**
   - Механика одиночного оспаривания больше не нужна
   - Вместо этого: `session.lastMoveBy: userId` — кто последний положил карту

4. **Добавить поле `session.turnOrder`** — массив userId в порядке ходов
   - `session.currentPlayerIndex` — индекс текущего игрока в turnOrder

5. **Миграция БД**: Добавить в `turns` поле `is_chain_valid` (boolean) для записи результата проверки всей цепочки

### Этап 2: Игровой движок (engine.js)

**Файл:** `backend/src/game/engine.js`

1. **Новая функция `dealHand(deckCards, usedCardIds, handSize)`**
   - Раздаёт `handSize` (3-5) карт из колоды
   - Возвращает массив карт для руки + обновлённый `usedCardIds`

2. **Переписать `validateMove()`**
   - Сейчас: проверяет одну карту vs. соседей
   - Нужно: убрать валидацию при ходе — карту можно положить куда угодно (игрок не знает значения)
   - Валидация происходит только при оспаривании

3. **Новая функция `validateChain(chain)`**
   - Проверяет ВСЮ цепочку: `chain[0].hiddenValue ≤ chain[1].hiddenValue ≤ ... ≤ chain[n].hiddenValue`
   - Возвращает `{ valid: boolean, invalidPositions: number[], lastWrongPlayer: userId }`
   - `lastWrongPlayer` — тот, кто положил карту, нарушающую порядок (последний по времени)

4. **Новая функция `revealChain(chain)`**
   - Переворачивает все карты: `isFaceDown: false` для всех

5. **Переписать `resolveChallenge()`**
   - Сейчас: проверяет 1 карту блефа
   - Нужно:
     ```
     resolveChallenge(chain, challengerId) → {
       chainValid: boolean,
       revealedChain: chain (все перевёрнуты),
       penaltyPlayer: userId,      // кто получает штраф
       penaltyCards: number,        // сколько карт из колоды берёт
       invalidPositions: number[]   // подсветка ошибок
     }
     ```
   - Если цепочка верна → `penaltyPlayer = challengerId`
   - Если цепочка неверна → `penaltyPlayer = lastWrongPlayer`

6. **Убрать `isBluff` параметр из `insertCard()`**
   - Все карты вставляются как `isFaceDown: true`

7. **Изменить `isGameOver()`**
   - Сейчас: `chain.length >= 10 || !remainingCards`
   - Нужно: игрок с 0 картами в руке побеждает ИЛИ колода закончилась → считаем очки

8. **Переписать `getWinners()`**
   - Побеждает тот, у кого меньше всего карт в руке (или 0 карт)

### Этап 3: Оркестрация сессии (session.js)

**Файл:** `backend/src/game/session.js`

1. **Переписать `createSession()`**
   - Раздать каждому игроку 3-5 карт (вызов `dealHand`)
   - Выложить 1 стартовую карту face-up в chain
   - Установить `turnOrder` и `currentPlayerIndex = 0`
   - НЕ отправлять `hiddenValue`/`displayValue` карт руки клиенту

2. **Переписать `processMove()`**
   - Убрать `isBluff` параметр
   - Игрок выбирает карту из руки (`cardId`) и позицию (`position`)
   - Карта удаляется из руки игрока
   - Карта вставляется в chain как `isFaceDown: true`
   - `session.lastMoveBy = userId`
   - Передать ход следующему игроку (`currentPlayerIndex++`)
   - Проверить, если у игрока 0 карт → gameOver

3. **Переписать `processChallenge()`**
   - Любой игрок (кроме того, кто сделал последний ход) может вызвать
   - Вызывает `resolveChallenge(chain, challengerId)`
   - Переворачивает всю цепочку
   - Штрафной игрок берёт N карт из колоды (или +N очков штрафа)
   - После оспаривания: начинается НОВЫЙ раунд
     - Цепочка сбрасывается
     - Новая стартовая карта выкладывается
     - Или: карты из цепочки убираются, оставляя только стартовую

4. **Добавить `joinSession(sessionId, userId)`**
   - Для GROUP: игроки присоединяются до начала
   - Раздаёт руку новому игроку
   - Добавляет в `turnOrder`

### Этап 4: API endpoints

**Файл:** `backend/src/api/routes.js`

1. **POST `/api/sessions/:id/move`**
   - Убрать `isBluff` из тела запроса
   - Валидация: карта должна быть в руке игрока
   - Валидация: сейчас ход этого игрока

2. **POST `/api/sessions/:id/challenge`**
   - Убрать привязку к `pendingChallenge`
   - Доступно любому игроку, чей ход наступил (вместо хода можно оспорить)
   - Или: отдельная кнопка доступна всем, кроме последнего ходившего

3. **GET `/api/sessions/:id`**
   - Санитизация ответа: НЕ возвращать `hiddenValue` для карт в руке
   - НЕ возвращать `hiddenValue` для `isFaceDown` карт в chain
   - Возвращать `hand` текущего игрока (без скрытых значений)

4. **POST `/api/sessions/:id/join`** (новый endpoint)
   - Для группового режима: присоединиться к сессии

## Риски и вопросы

1. **Штраф — карты или очки?** В правилах сказано "штрафные очки или карты из колоды". Предлагаю: штрафной игрок берёт 2 карты из колоды (увеличивает руку = отдаляет от победы).

2. **Что после оспаривания?** Цепочка сбрасывается и начинается заново? Или продолжается с раскрытыми картами? Предлагаю: цепочка сбрасывается, выкладывается новая стартовая карта.

3. **SOLO режим** — в новых правилах нет смысла в SOLO (некому оспаривать). Варианты:
   - Убрать SOLO
   - Оставить SOLO как тренировку (игрок угадывает порядок, очки за правильные позиции)
   - Добавить AI-оппонента

4. **Групповой режим в чате** — описан упрощённо (Left/Right). Это отдельная механика от основной Mini App игры. Реализовать как параллельный режим.

5. **Количество карт в руке** — захардкодить 5 или сделать настраиваемым в колоде?
